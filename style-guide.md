# Acicalados — Style Guide

## Color Palette

| Token | Hex | Usage |
|-------|-----|-------|
| `--color-primary` | `#D4AF37` | Primary gold — buttons, headings, CTAs |
| `--color-primary-dark` | `#C2872B` | Dark gold — hover, accents |
| `--color-primary-light` | `#F5E6B3` | Light gold — backgrounds, borders |
| `--color-bg` | `#0A0A0A` | Main background (dark) |
| `--color-bg-card` | `#141414` | Card surfaces |
| `--color-bg-elevated` | `#1A1A1A` | Elevated surfaces |
| `--color-text` | `#F5F5F5` | Primary text (light on dark) |
| `--color-text-muted` | `#A0A0A0` | Secondary text |
| `--color-success` | `#22C55E` | Success states |
| `--color-warning` | `#F59E0B` | Warning states |
| `--color-error` | `#EF4444` | Error states |

## Typography
- **Primary font:** Inter (Google Fonts)
- **Heading weights:** 600–700
- **Body weight:** 400

## Border Radius
- Buttons: `8px`
- Cards: `12px`
- Modals: `16px`

## Shadows
- Card: `0 4px 20px rgba(0, 0, 0, 0.3)`
- Elevated: `0 8px 40px rgba(0, 0, 0, 0.5)`
